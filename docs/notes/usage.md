# 图表笔记

主导航的「笔记」支持新建文字笔记、自定义分组、修改及删除。

任意股票的「K 线研究」中：

1. 先选择周期、指标及缩放范围，点击「标注并记笔记」。
2. 在保存的图表快照上点击输入文字，或按住拖动绘制箭头、框选和画线。
3. 填写标题、分组和正文。停止编辑约 0.6 秒后自动保存；点击「保存并关闭」保留修改并退出；点击「直接关闭」放弃本次打开后的修改（包括已经自动保存的修改），新建笔记则不保留。
4. 直接在图上选中、拖动标注，双击原位编辑文字；调整字号、线宽、颜色或删除选中项。支持 Delete 键删除及撤销、重做。
5. 在「笔记」栏目或股票的「该股票的图表笔记」入口打开同一篇笔记，继续修改。

图表保留当时的可视范围、指标及条件标记，不随行情更新。新增的笔记标注只画在该快照上；「查看该股票最新行情」打开当前行情。它不修改原有的支撑压力线，也不参与选股计算。

数据持久化在系统数据库的独立研究笔记表。列表不传输图片；打开一篇笔记才读取快照。删除分组会保留笔记并移到未分组。并发修改会提示版本冲突，避免静默覆盖。

## 拖拽编辑

标注工具现支持直接按住拖动绘制箭头、线条和矩形。绘制后自动切换到选择模式，可直接拖动图形或文字；选中的非文字标注显示两个端点控制柄，可以调整位置、方向或尺寸。双击文字原位编辑，工具栏调整选中项的字号（10—64）、线宽（1—10）和颜色。支持本次编辑中的撤销、重做。旧标注未保存字号和线宽时沿用16及2，保持兼容。拖动过程中只预览，松开后自动保存。
