# Sequoia 选股

来源：[sngyai/Sequoia-X](https://github.com/sngyai/Sequoia-X)，参考提交 `444c0db69ff36b46ef2b22ab265051d60c16029d`（2026-09-14 获取）。上游 README 声明 MIT，作者 sngyai；本模块按公开规则重新实现，未引入或运行上游同步器、飞书发送器、SQLAlchemy 引擎。

## 使用

1. 主导航进入「Sequoia 选股」，选择策略分组和参数。每个策略内部条件全部满足；可设置同一交易日至少命中 1～已选策略数个策略。默认为 1，兼容旧记录。
2. 选择截至日期、全市场或指定自选分组，开始筛选。定增策略只允许今天查询。
3. 结果按策略分组查看，单股票多组命中分别保留。诊断区给出成立、不成立、数据不足和部分缺失实例。
4. 点击股票进入详情；每个策略独立展示逐条实际值和阈值。点击依据只显示其 K 线区间/成交量标注，支持恢复全部标注。
5. 勾选当前结果后批量添加：可指定已有自选分组，或创建/复用「Sequoia · 策略名」分组。多策略命中会加入多个分组。保留原有来源和分组，同一次运行重复添加不会重复保存来源。
6. 历史记录保存运行配置、计算日期、逐组诊断和命中依据快照。JSON 配置可粘贴、文件导入、输出到编辑框；本板块 JSON 与通用条件树不是同一格式。

## 与上游的适配差异

- 使用本系统 `market_features` 日线统一口径，不拼接上游后复权历史和未复权实时行情。不改已有条件选股、回测与行情采集算法。
- 参数默认值与七个上游实际策略一致；高紧旗形不检查突破，也不检查低点/高点先后；上升趋势大跌不检查反包。
- 上游涨停/跌停策略使用固定 ±9.5% 阈值。本界面称「大涨后放量阴线」「上升趋势放量大跌」，不将其视为交易所实际涨跌停。
- 均线交叉需要 21 根，昨日 MA60 需要 61 根，修正上游最小数据检查；缺失/无效价格明确归为数据不足。
- RPS 使用所选市场日、全市场有完整 121 根日线的股票，120 日涨幅百分位，平级取平均排名。切换自选范围不会改变排名母体。仅使用截至日以前记录，停更股票不冒充当日信号。
- 成交额以元计算，量使用同一数据源口径。均线金叉和趋势大跌的 20 日均量含当日，高紧旗形的均量不含当日。
- 海龟已按用户要求改为：收盘大于此前20日最高价、当日量/此前20日均量 ≥ 1.5（不含当日，窗口和倍数可调）、阳线且高于昨收；不再限制固定成交额。本模块不使用当前流通市值对历史结果排序；提供代码和当日涨跌幅排序。
- 定增沿用东方财富全部增发数据（AkShare `stock_qbzf_em` 的来源），增加请求超时，限制近 90 日取数。按发行日期过滤且排除未来；不称其为公告发布日期，不提供历史时点/回测支持。图中以发行日起首个可用交易日作事件标记，休市日不虚构 K 线；发行日晚于最新日线时不画标记。
- 上市日期未知的当前在市股票兼容纳入，并显示数量；退市日期未知且不在市股票排除。历史筛选可能有幸存者偏差，不宣称历史回测或可交易性结果。
- 新增独立 `sequoia_runs` 表；进行中的运行在服务重启后标为失败，可手动重跑。定增失败时其他策略继续计算，定增组明确报错，不伪装成零命中。

## 改动边界

主体在 `src/astock/sequoia/` 与 `web/src/features/sequoia/`。共享改动仅 API 注册、一个主导航入口/移动端列数、来源树可选分组标题展示。现有图表使用原有 ConditionMark 接口；没有修改图表计算或其他策略算法。

## 历史范围识别

新增 `period`：`latest`（兼容旧配置的默认值）、`1y`、`2y`。历史起点按请求截至日期减去一或两个自然年；只输出范围内实际有日线的交易日信号。一次读取目标期间与之前最多251根预热日线，在内存中逐日推进，计算窗口不包含未来数据。

RPS 使用各历史日全市场有效数据计算，随后才筛自选范围；上市/退市日期按观察日过滤，未知上市日期仍提示可能的幸存者偏差。定增仅有当前名单，不允许历史范围。停更股票不会用旧行情冒充缺失交易日。

结果按股票去重，每个策略组保留 `occurrences` 中的全部命中日期和条件依据；加入自选保持策略分组和历史标记。结果报价是截至所选日期的最近可用记录，显示具体报价日期；诊断成立/不成立/未知统计为股票×交易日次数，不等于去重股票数。后台显示逐日进度，全市场两年比单日运行工作量大。

海龟历史结果按阶段计次：首次满足时锁定当时前高 `breakout_level`，之后回调、缩量或再次满足入选条件均不新增信号；仅在有效收盘严格低于该固定前高时结束。等于前高不结束，缺失行情不推断跌破。结束日记为 `ended_on`，`end_date` 为此前最后一根有效阶段内日线，`days` 为实际观察到的有效阶段内日线数。下一次重新满足入选条件开始新阶段。每阶段默认仅标记首日，具体条件的历史参考窗口可点击查看。阶段状态从请求范围内开始建立，范围起点之前的阶段不追溯。其他策略保持逐日命中规则。分组页签显示信号次数，诊断仍统计逐日条件真假。旧运行快照保持原样，需重新运行使用新版规则。


### 海龟涨停突破豁免（v2）
收盘必须严格突破此前 N 日最高价并高于昨收。普通分支仍要求阳线及当日量 / 此前均量达到配置倍数；收盘真实涨停分支豁免放量及阳线要求，包含一字板。核验使用本地未复权日线收盘价与同日 security_status.limit_up，按分位四舍五入比较，排除停牌及未完成日线。缺少可靠涨停价格或未复权日线时不推测涨停，只走普通分支。盘中触板而收盘未涨停不能豁免。
最新与历史采用同一规则，固定首次前高的阶段结束规则不变。既有运行快照不重写，需要重新运行。只读取潜在价格突破股票对应年份的本地文件，不触发网络补数。

## 多策略同日筛选与图表图例

`minimum_matches` 为整数，默认 1，不能超过选择的策略数。最新模式仅统计数据日各策略的独立命中；一年、两年模式逐交易日统计，不把不同日期的信号拼成同一次命中。结果仅保留达到门槛的日期及当天命中依据；原有策略诊断仍统计各策略本身的成立、不成立、数据不足次数。历史海龟信号沿用固定首次突破前高的阶段合并规则。

Sequoia 详情图默认把每个命中策略每个日期压缩为一个彩色菱形信号，悬停显示策略名；策略图例可分别点亮、点灭，避免多条内部条件的窗口框重叠。下方逐条条件依据仍可点击，临时只看该项参考区间。结果保存完整条件证据；旧运行记录展示时也可使用新图例，不重算旧策略结果。
