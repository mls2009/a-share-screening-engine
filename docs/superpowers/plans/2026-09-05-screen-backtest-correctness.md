# 条件选股与回测正确性实施计划

**目标：** 落实上一轮审查中影响结果正确性的周期、股票池、价格尺度和数据诊断问题。

**设计：** 保留已有条件树、数据库和界面结构。周/月信号由完整周期计算，执行时钟采用日线。
跨周期数据按可用时间对齐。现有用户指令已授权实施审查建议，直接进行可逆代码修改和验证。
历史数据未知时返回明确诊断，不虚构交易日、上市状态或复权系数。

**技术栈：** Python / pandas / DuckDB / FastAPI / React / pytest / Vitest / Playwright。

- [x] 周期完整性：添加交易日历辅助函数；派生K线传播完成状态；清除重算区间的旧周/月部分周期特征。
  修改 data/service.py、features/builder.py、features/store.py；增加假期周末、周中截止、月中截止测试。
- [x] 选股：修复跨周期时间匹配、历史股票池和数据诊断；改进指标能力声明；用API及界面测试证明缺失数据可见。
- [x] 回测：分离信号K线与执行K线，准确标注成交时间，按开盘而非未来高低价检查限制；统一涨跌停价格尺度。
  修改 backtest/engine.py、service.py、models.py；增加周/月下一交易日、跳空、无价格换算依据测试。
- [x] 回测报告：展示数据与预热覆盖、拒单原因；限制历史切片长度，保持已有策略信号不变。
- [x] 集成验证：pytest、ruff、前端单测、生产构建及桌面/手机浏览器测试；更新审查记录，明确数据边界。

每项按“先复现失败 → 最小实现 → 定向测试 → 复核”执行，不修改用户数据库原始行情，不创建提交。
