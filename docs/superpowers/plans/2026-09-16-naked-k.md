# 裸K四选二实现计划

目标：实现已确认的日线看涨/看跌Pinbar条件；无副影线限制、无入场门槛、无评分指标。
架构：独立因果派生指标模块；条件树AND/OR表达四选二；选股、自选筛选与回测共用函数；按需加载不重写历史数据库。

1. 编写形态边界、假突破、位置、四选二和未来数据不变测试，确认失败。
2. 实现日线派生指标与周线已确认趋势。水平位沿用左右2根拐点、至少2触点和现有带宽规则，回看120日；信号前冻结。
3. 注册指标，接入所有历史读取、实时限制、回测和标注调用点；生成看涨/看跌JSON。
4. 运行相关测试、真实服务JSON校验及有限样本筛选；更新设计文档使其不再包含过时入场条件。

验证标准：>2/3严格边界、不限制副影线；2/4六组合；缺数据保留未知；追加未来数据不改变旧结果；导入和筛选一致。
