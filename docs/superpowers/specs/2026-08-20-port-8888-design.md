# 一体化服务端口改为 8888

日期：2026-08-20

## 目标

将 AStock 一体化 FastAPI 服务的标准启动端口和正式访问地址从 `8000` 改为
`8888`。Vite 前端开发服务器继续使用 `5173`，避免把生产访问端口与开发端口混为
一谈。

## 变更范围

- README 中两条 Uvicorn 启动命令改用 `--port 8888`。
- README 中浏览器访问地址改为 `http://127.0.0.1:8888`。
- 不修改 API 路由、数据库、前端请求路径或 Playwright 的 Vite 测试端口。
- 使用端口 `8888` 启动服务并请求健康的现有 HTTP 接口，确认能够访问。

## 成功标准

1. 项目说明中不再把 `8000` 作为标准服务端口。
2. `127.0.0.1:8888` 能启动一体化服务并返回正常 API 响应。
3. 现有后端、前端测试不受影响。
