# 取消自动趋势线设计

## 目标

系统不再计算、存储或展示自动上升趋势线和自动下降趋势线，并清除数据库中已经生成的自动趋势线。

## 保留范围

- 自动水平支撑线和自动水平压力线保持不变。
- 手动画趋势线功能保持不变。
- 已有手动趋势线保持不变。
- 手动线删除和自动水平线删除后的重现规则保持不变。

## 实现方案

1. `detect_zones()` 只返回自动水平支撑/压力线，不再调用方向趋势检测。
2. 图表查询对历史自动趋势线做防御性过滤，即使数据库尚未清理也不会返回给前端。
3. 数据库迁移幂等删除 `source = 'auto' and geometry = 'trend'` 的存量记录，只清理自动趋势线。
4. 保留前端手动趋势线绘制与展示逻辑；不新增功能开关。

## 数据流

K 线数据进入特征构建器后，只生成水平支撑/压力线。图表接口返回自动水平线和手动画线。启动时数据库迁移清除旧自动趋势线，确保已经画出的自动趋势线从持久化数据中消失。

## 验收标准

- 任意周期的自动检测结果中不存在 `geometry = trend`。
- 图表接口不会返回 `source = auto` 的趋势线。
- 数据库迁移后不存在自动趋势线记录。
- 手动趋势线仍能创建、查询和显示。
- 自动水平支撑/压力线行为不变。
- 全量后端、前端和浏览器测试通过。
