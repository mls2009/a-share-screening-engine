# 可删除支撑压力线与日线趋势候选设计

## 目标

- K 线研究中的自动线和手动画线都能单独删除。
- 正常生成的支撑压力线统一使用实线。
- 被用户删除的点位以后再次被算法识别时仍可显示，但改用虚线。
- 日线在具备至少两个有效高点和两个有效低点时，始终显示一条最优趋势支撑和一条最优趋势压力。

## 非目标

- 本次不增加删除历史管理页、恢复按钮或批量删除。
- 本次不改变水平支撑压力的识别算法。
- 周线、月线和分钟线继续使用现有严格趋势识别逻辑。

## 删除历史

新增 `zone_deletion_markers` 表，记录被删除线的：

- `marker_id`
- `symbol`
- `timeframe`
- `geometry`
- `lower_price`
- `center_price`
- `upper_price`
- `deleted_at`

删除任意支撑压力线时，服务端在同一事务中先写入删除标记，再删除当前线记录。接口改为通用的 `DELETE /api/symbols/{symbol}/zones/{zone_id}`，不再限制 `source = 'manual'`。股票或线编号不匹配时返回 404，且不写删除标记。

删除标记不会因为自动特征重算而被清理。再次删除同一价格范围只需保留可匹配的历史，不需要在本次提供恢复能力。

## 再次出现的判定

读取当前支撑压力线时，在以下条件全部成立时标记 `reappeared = true`：

- 股票相同；
- 周期相同；
- 形态相同，即水平线只匹配水平线、趋势线只匹配趋势线；
- 新线的 `center_price` 落在删除记录的 `[lower_price, upper_price]` 中。

匹配不比较支撑或压力类型。这样同一价位发生支撑压力转换后仍视为同一被删除点位。

API 为每条线返回布尔字段 `reappeared`。未命中删除历史的线为 `false`；命中任一删除标记的当前线为 `true`，不区分当前来源是自动还是手动。

## 线型和删除交互

- `reappeared = false`：实线。
- `reappeared = true`：虚线。
- 颜色仍只由当前角色决定：支撑绿色、压力红色。
- 线条列表中的每一项都显示删除按钮，不区分自动或手动来源。
- 删除成功后立即从图表和列表移除；删除失败时保留原线并显示错误信息。
- 图例改为“正常实线 / 删除后重现虚线”，避免继续用来源解释线型。

## 日线趋势候选

现有算法只对最后五个拐点做一次回归，并同时要求拟合误差在容差内、投影位于现价正确一侧。600519.SH 当前日线的低点回归投影在现价上方，高点回归误差又超过容差，所以两类趋势线都没有生成。

日线改为分两级选择，其他周期保持原逻辑：

1. 从最近 12 个低点或高点中，枚举长度为 2 至 5 的连续拐点窗口；每一类最多生成 38 个候选，避免全市场同步时出现组合爆炸。
2. 对每个窗口执行最小二乘拟合，计算最新投影、平均绝对残差、最后触点日期以及距现价距离。
3. 先筛选投影角色正确且残差不超过现有容差的确认候选：支撑必须低于现价，压力必须高于现价。
4. 确认候选按触点多、标准化残差小、最后触点新、距现价近的顺序选择。
5. 如果没有确认候选，则从角色正确的全部窗口中，按标准化残差小、触点多、最后触点新、距现价近的顺序选择最佳备用候选。
6. 如果所有窗口的投影都位于错误一侧，则选残差最小的窗口，将整条线平移到现价外一个容差：支撑位于 `latest_close - tolerance`，压力位于 `latest_close + tolerance`。返回的两个端点使用平移后的线值，保证前后端绘制一致。

因此，只要日线窗口内至少存在两个低点和两个高点，系统就能分别返回一条趋势支撑和趋势压力。备用候选仍是正常算法结果，使用实线；只有命中删除历史的再次出现线才使用虚线。

## 数据流

1. 特征重算生成当前自动水平线与趋势线。
2. 用户在列表中删除任意线。
3. 后端保存该线价格容差并删除当前记录。
4. 后续重算可能再次生成相近线。
5. 查询接口将当前线与删除标记匹配，补充 `reappeared`。
6. 前端根据 `reappeared` 选择实线或虚线。

## 测试与验收

- 数据库测试：删除标记表可初始化并持久保存。
- 后端测试：自动线和手动画线均可删除；错误股票不能删除。
- 后端测试：新线中心价落入原容差后返回 `reappeared = true`，支撑压力转换不影响匹配。
- 算法测试：旧算法会拒绝的日线数据仍返回一条趋势支撑和一条趋势压力，两条线位于现价正确一侧。
- 前端测试：所有线都有删除按钮；正常线为实线；再次出现线为虚线；删除失败不从页面移除。
