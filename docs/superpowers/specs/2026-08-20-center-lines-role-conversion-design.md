# 支撑压力中心线与角色转换设计

日期：2026-08-20

## 目标

K线图不再显示支撑压力价格区间，只显示一条清晰的中心线；自动识别的历史支撑和
压力根据当前价格重新判定角色。修复周线趋势支撑存在于 API 结果中但未显示的问题。

## 图表表现

- 水平区域只在 `center_price` 处绘制贯穿图表的水平线，不绘制 `markArea` 色带。
- 趋势区域以锚点拟合出的中心线绘制，并从第一个可见锚点延伸到最新 K 线。
- 支撑使用绿色，压力使用红色。
- 自动线使用 2 像素虚线，手动线使用 3 像素实线。
- 线尾显示类型和当前线价，例如“自动支撑 1291.45”。
- 下方列表改称“支撑压力线”，只显示中心价格，不显示上下界范围。
- 画线工具中的“水平区间/趋势区间”改称“水平线/趋势线”。

## 周线趋势线修复

数据库锚点使用 `YYYY-MM-DD`，K线横轴使用带时区的 ISO 时间戳。前端按日期部分把
锚点映射到对应 K 线索引，再用索引计算斜率并向右延伸。这样日、周、月以及分钟线
不依赖时间戳字符串完全相等。

## 支撑压力转换

- 只转换 `source=auto` 的自动识别线。
- 自动线中心价低于当前收盘价时归类为支撑，高于当前收盘价时归类为压力。
- 手动画线始终保留用户选择的支撑/压力类型和颜色。
- 数据库存储的原始区域和上下界不修改，筛选和历史审计仍可使用原始记录。
- API 在选取离现价最近的线之前完成角色转换，再分别返回最近的支撑和压力。

## 验证

- 后端测试覆盖跌破支撑后转为压力、突破压力后转为支撑，以及手动画线不转换。
- 前端测试确认没有 `markArea`、水平中心线价格正确、趋势线日期能够匹配并延伸。
- 页面测试确认列表和画线工具使用“线”而不是“区间”。
- 完整运行 Python、前端单元测试、生产构建和浏览器测试。
