# AStock 全站手机端适配设计

日期：2026-08-24

## 目标

让条件选股、K 线研究、策略回测和实时监控在常见手机竖屏与横屏下可完整操作。桌面端现有信息密度和布局保持不变，K 线研究作为重点，提供横屏全屏看盘。

## 适配范围

- 竖屏基准：375×812、390×844、430×932。
- 横屏看盘基准：844×390。
- 所有交互控件保证至少 44px 的有效触摸区域。
- 页面不产生整体横向溢出；确需宽内容时，仅在组件内部横向滚动。
- 兼容全面屏底部安全区域。

## 全局框架

桌面端继续使用左侧导航。屏幕宽度不超过 760px 时，将导航改为固定底部栏，保留条件选股、K 线研究、策略回测和实时监控四个入口。隐藏桌面品牌区与数据库状态，主内容为底部栏和安全区域预留空间。

页面标题、运行按钮和状态信息在手机端纵向排列。输入框、选择器、菜单和危险操作都扩大触摸面积，错误与成功提示允许自动换行。

## 条件选股

筛选日期、运行方式和运行按钮在手机上采用两列后转单列的布局。条件组保持逻辑层级，但每条条件从桌面横向网格改为卡片：指标路径占满一行，周期、比较符、值和删除操作按屏幕宽度排列。

结果区域在手机端取消右侧固定详情布局，详情移到列表下方。表格包裹在内部横向滚动容器中，证券代码与名称保持可识别，“查看 K 线”按钮保持可触摸。分页控件允许换行，并保留上一页、下一页和每页数量。

## K 线研究

竖屏顶部依次显示搜索、股票与最新价格、周期工具栏、指标工具栏和画线工具栏。周期、指标和画线工具栏允许横向滚动，不强制把所有按钮压缩在同一屏宽内。

图表减少左右边距并占满可用宽度。主图、成交量和指标副图继续纵向共享时间轴；增加副图时图表高度同步增长。手势约定如下：

- 普通模式：单指移动十字线，双指缩放与拖动时间窗口。
- 画线模式：点击主图记录锚点，工具栏明确显示当前画线状态和取消入口。
- 自动支撑压力值仍通过图表提示显示。

增加“全屏看盘”按钮。全屏模式隐藏应用导航、页面标题和支撑压力列表，只保留股票信息、周期、指标、画线和图表。设备支持时请求横屏；不支持或拒绝旋转时仍进入占满视口的看盘模式。退出按钮始终可见，退出后恢复原滚动位置和所选周期、指标、画线状态。

支撑压力列表在手机竖屏中使用单列卡片，删除按钮不小于 44px。

## 策略回测

配置区在中等屏幕使用两列，在窄屏使用单列。运行按钮放在标题下方并占满可用宽度。入场和离场条件由桌面双列改为纵向排列，并复用选股条件卡片规则。

回测指标使用两列卡片；权益曲线占满宽度；交易明细保留内部横向滚动，避免撑宽页面。

## 实时监控

运行状态和启动/停止按钮在标题下方并排展示。摘要卡片在手机端使用两列。新建规则表单改为单列，创建按钮占满宽度。

监控任务和最近触发由桌面双列改为纵向布局。任务操作按钮和删除按钮扩大触摸区域，长证券列表允许换行。

## 组件边界

- `App` 只负责桌面侧栏与手机底部导航切换。
- 各页面保留自身数据状态，只调整结构类名和移动端交互。
- `StockChart` 负责图表尺寸、全屏状态和尺寸变化后的 ECharts 重排。
- `ConditionTree` 提供条件卡片的响应式结构，供选股与回测共同使用。
- CSS 使用现有 760px 断点，并按需要增加横屏全屏媒体规则，不另建第二套页面。

## 错误与降级

- 全屏 API 或屏幕方向锁定不可用时，继续使用 CSS 视口全屏，不阻断看盘。
- 旋转、浏览器地址栏收起和软键盘弹出时重新计算图表尺寸。
- 数据读取、筛选、回测和监控错误沿用现有提示，不改变后端接口。

## 验证

- 组件测试覆盖手机底部导航、K 线全屏进入/退出和工具栏状态保留。
- 图表测试覆盖容器尺寸变化后的 `resize`。
- Playwright 分别使用 375×812、390×844、430×932 和 844×390，验证四个模块可访问、无页面级横向溢出、主要操作可见可点。
- 最终运行全部前端测试、生产构建和后端回归测试。

## 非目标

- 不重写视觉主题。
- 不开发独立手机应用或第二套 React 页面。
- 不修改行情、筛选、回测和监控的后端业务逻辑。
- 不增加用户登录或公网访问能力。
