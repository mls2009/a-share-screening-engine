# 相同条件筛选的新增标识

自动选择本次创建前已完成的最近一次运行作为基准，要求规范化条件树、选股范围和运行模式相同。AND/OR组内条件顺序不同不影响匹配；日期不同允许比较。股票范围、分组、来源结果不同不混比；失败或尚未完成的运行不作基准。

结果上方显示上次完成时间、数据截止日期及新增数量，股票名称旁显示“新增”。首次运行没有可比较记录时明确提示，不把全部命中当新增。

“仅看新增”在服务端分页前过滤，排序、翻页及当前显示总页数都针对新增集合；此模式下全选、批量加入自选也只处理新增。切换筛选时清空勾选，避免误加入其他集合。普通模式仍显示全部命中。历史记录按当时之前的运行比较，不会因后来新增运行而改变参照。
