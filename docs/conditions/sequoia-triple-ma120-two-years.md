# Sequoia 三策略同日共振＋MA120

导入同目录 `sequoia-triple-ma120-two-years.json`，或在条件选股加载“Sequoia三策略共振＋MA120（近两年·2倍量·10%）”。使用收盘模式。

查询数据日期往前两个自然年（包含首尾日期），记录所有满足以下四项的同一根日 K：

1. 海龟突破：沿用 Sequoia 前20日最高价突破、收盘高于昨收等规则；当日成交量至少为此前20日平均成交量的2倍，不含当日。已确认的真实涨停豁免海龟的成交量和阳线要求，包含一字板；但组合中的均线金叉仍需满足自身的2倍放量要求。
2. 均线金叉放量：昨日MA5 < MA20，当日MA5 > MA20；当日成交量至少为包含当日在内20日平均成交量的2倍。均量口径沿用 Sequoia，恰好2倍也满足。
3. RPS强势近高点：120日收益率在当日全市场有效股票中排名百分位≥90，收盘≥最近120日最高价的90%。即使筛选指定分组，排名基准仍为全市场。
4. MA120：开盘≤当日MA120且收盘>当日MA120；或者MA120<开盘≤MA120×1.10。后一分支仅约束开盘位置，不额外要求收盘高于MA120。

不要求今天满足；三策略不能分散到不同日期成立。每个命中日期各有一处图表标记，保存命中日开盘、收盘及MA120数值；添加自选时保留标记。

这是固定组合的收盘选股条件，目前不提供策略回测。原 Sequoia 策略默认参数与涨停豁免不受此组合影响。
