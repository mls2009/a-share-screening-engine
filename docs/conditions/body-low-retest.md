# 两年独立实体低点回访（日线）

默认模板筛选最新日线首次回访事件，不是仅判断价格一直位于底部区域。可主动选择历史数据日期观察当时结果；JSON可用于条件选股和策略回测。策略本身不是买入建议。

1. 参照价为min(开盘,收盘)。候选必须低于前5根实体低点，后5根实体低点均不更低。确认完成后下一交易日才可作为参照，避免未来数据。
2. 仅选择观察日之前两年（自然年）的候选，可读取窗口前5根作为转折背景；上涨途中的窗口边界不自动成为低点。
3. 两个候选之间，至少一根实体低点高于两者较高价格的105%，才视为独立转折。否则合并，保留更低者；相同价格保留较早者。
4. 按价格取最低、次低，必须有两个独立低点；不足两个为数据不足。
5. 候选确认后，至少有一根完整K线在参照价±5%区域外，随后K线的高低区间再次与区域重叠，记录一次回访。允许从区域上方或下方回访，影线也算，边界包含。连续停留不重复触发。
6. 图中标记两个参照区域、候选及确认日期和本次回访。保留已运行的历史快照，不随新低点反向修改。
