# 日线缩量急跌区间

按用户确认的日线口径独立筛选，不要求分钟或逐笔数据。以急跌段和此前20日的平均成交股数比较缩量程度，不引入价格带成交密度条件。

新增必要条件：急跌段日均成交股数 / 起点之前20个交易日日均成交股数 ≤0.8。起点当日不混入基准。缺少成交量时返回数据不足。成交股数比值不是换手率，股本变化可能影响比较。
保留以下急跌/远离/重入/MA120及250日规则。JSON字段保留兼容，界面、模板、图形均改称缩量急跌区间。历史结果仍属旧版，需要重跑。

# 急跌、远离和重入时序

## 当前规则

- 日线起点最高价为截至起点最近20根最高价。
- 急跌段含首尾3～5根，跌幅（起点最高－终点最低）/起点最高严格>25%。
- 段内每次相邻收盘下跌≥2%，收盘下跌效率≥80%，无连续3根整体振幅≤3%的平台。
- 首次相邻收盘跌幅不足2%时结束，放缓那根不纳入区间；需等这根收盘才确认，不回填未来信号。满5根则当日确认并固定。
- 上沿为起点最高、下沿为终点最低；终点为段内新低。后续缓跌不延长或下移区间。
- 确认日若已在急跌段之外，可以计入离开区间阶段。
- 收盘≤下沿×95%记为首次明显远离。之后第3～20个交易日才允许重入。
- 重入前至少连续5根收盘严格低于下沿。
- 前收≤下沿、今收>下沿且今收<上沿时重入。首次返回即消耗此次离开事件；不符合停留要求的立即反弹不触发，也不再复用该区间。
- 多区间独立判断，当日任一区间符合即命中；展示最新确认的命中区间。
- 当日版本再AND收盘>当日MA120。
- 一年版本为最近250根内至少一天同时重入且站上该日MA120，不要求今天仍满足。

## 使用

收盘模式下加载「缩量急跌区间重入（跌幅>25%）＋站上MA120」或「近一年缩量急跌区间重入＋当日站上MA120（跌幅>25%）」模板。
JSON文件：`vacuum-reentry-ma120.json`、`vacuum-reentry-ma120-year.json`。字段不变，计算使用当前规则，旧历史筛选记录保持原结果，需重新运行。
条件选股、自选历史扫描和回测共用识别器；详情/自选来源保留形成范围、固定上下沿及命中日期。
按需读取本地特征，不重建数据库、不触发行情补更。

## 验证

覆盖缓跌尾段排除、未来数据截断一致性、25%严格边界、5%远离、连续5根在下方、3天最小等待、20天最大等待、250根回看窗口和筛选/回测一致性。
MA120（青色）及MA250（浅灰色）属于默认均线，缺少足够历史时不虚构数值。
