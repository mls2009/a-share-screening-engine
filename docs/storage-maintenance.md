# 行情更新与空间整理（2026-09-15）

本次修复将主、备用行情源接入 `FeatureBuilder.build_incremental_symbol`。对比日、周、月行情输入，只重写最早变化日期起的指标；未变化且上次构建完整时不写入。新增行情、历史修正和缺失周期记录都自动检测。价格已保存但形态/区间构建中断时，根据构建标记回退完整重建。完整历史仍参与指标计算，避免截断 EMA 等指标。

备用源不再强制从月初重写，主源不再每次整段历史重写。保留低于 3 GiB 时暂停写入的保护。

## 已完成的数据库整理

- 原主文件 6,952,857,600 字节；重建后 3,381,932,032 字节，释放约 3.33 GiB 的文件占用。
- 使用 DuckDB `COPY FROM DATABASE` 新建紧凑数据库；原库停止写入、checkpoint 后复制。
- 所有表的结构、索引、行数，以及逐行全字段哈希的求和和异或校验一致。包括 5,273,778 条指标、4,699,158 条形态记录和自选、筛选、回测记录。
- 校验通过后替换；正式 8888 状态和自选接口 HTTP 200 后移除被替代文件。
- 实际数据根目录 `.worktrees/a-share-screening-engine/data`；逐表校验记录见其 `compaction-20260915.json`。
- 恢复备份改为 gzip，逐份验证解压后 SHA-256。各恢复目录的 `compressed-backups.json` 记录原路径、大小与摘要；原始损坏库与完整 WAL 保留。重复副本合并，可重建的中间恢复副本已清理。
- 清理后磁盘可用约 9.1 GiB（清理前约 3.6 GiB；受系统其他应用影响会变化）。
